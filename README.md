# Body Tracking

Считывание движений пользователя с камеры и перевод в нажатия клавиш/действия мышью.

---

### Запуск проекта

Текущее окружение проекта: Python 3.14, Linux с графической сессией X11 и веб-камерой.
Для управления мышью используется Xlib; работа в Wayland не поддерживается этим кодом.

Выполняйте команды из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.main
```

В папке `models/` должны находиться:

- `pose_landmarker_full.task` — распознавание тела;
- `face_landmarker.task` — управление взглядом;
- `gesture_recognizer.task` — только для эксперимента с жестами рук.

После запуска встаньте так, чтобы камера видела всё тело, и смотрите прямо около
секунды для автоматической калибровки головы. Свет должен падать на лицо.
При смене игрока предыдущий человек должен выйти из кадра, а новый — спокойно
посмотреть прямо для повторной калибровки.

Клавиши `C` и `V` работают при активном окне игры:

- `C` — повторная калибровка головы;
- `V` — включение/выключение управления взглядом;
- `Q` — выход, когда активно окно камеры.

Для Minecraft отключите Raw Input, если игра не реагирует на движение мыши.
Движения и клики отправляются активному приложению.

Проверки логики без камеры и отправки настоящих нажатий:

```bash
python -m unittest discover -s tests
```

### Управление

| Действие                       |     Кнопка |
|:-------------------------------|-----------:|
| Ходьба (шагание на месте)      |          W |
| Бег (высокое шагание на месте) |   W + Ctrl | 
| Удар правой рукой              |        ЛКМ |
| Много ударов правой рукой      | Зажать ЛКМ |
| Удар левой рукой               |        ПКМ |
| Вытянуть левую руку            | Зажать ПКМ | 
| Прыжок                         |      Space |
| Присед                         |      Shift |
| Поворот головы влево/вправо     | Поворот камеры по горизонтали |
| Подбородок вверх/вниз          | Поворот камеры по вертикали |
